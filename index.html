3. Manuales

Instrucciones paso a paso para usar y mantener la aplicación.

📘 Manual de usuario

  1. Prepara uno o varios CSV. Para ventas usa columnas de tienda, cantidad vendida y precio unitario o ingresos totales.
  2. Pulsa Cargar archivos en la sección superior y selecciona tus CSV de ventas. Agrega inventarios o satisfacción si los tienes.
  3. Comprueba los nombres de archivo mostrados. El sistema reconoce nombres habituales en español e inglés, como ID_Tienda, store, Cantidad_Vendida, quantity, Stock_Disponible y satisfaction.
  4. Pulsa Ejecutar análisis. Espera el mensaje de finalización y consulta indicadores, gráfico, tabla y hallazgos.
  5. Usa los botones para descargar tablas CSV, hallazgos CSV, gráfica PNG o informe Word. Para PDF pulsa Imprimir / PDF y elige “Guardar como PDF” en la ventana de impresión.
  6. Para empezar con los datos de muestra, pulsa Cargar ejemplo RetailNow. Luego puedes reemplazarlos cargando tus propios archivos.

Privacidad: la lectura y el análisis se hacen en tu navegador. Los archivos seleccionados no se transmiten al sitio.

🛠 Manual técnico

  1. Despliegue: GitHub Pages sirve este index.html y los recursos estáticos del repositorio.
  2. Interfaz: HTML5 organiza las secciones; CSS adapta el panel a escritorio, tabletas y móviles.
  3. Carga: los controles input[type=file] aceptan varios CSV. La aplicación lee cada archivo con File.text() sin subirlo a un servicio externo.
  4. Procesamiento: JavaScript separa columnas CSV respetando comillas, detecta separadores comunes, normaliza encabezados y agrupa ventas por tienda.
  5. Métricas: calcula ingresos, unidades, media, mediana, desviación estándar, rotación de inventario, productos con menos de 10% vendido y satisfacción inferior a 60%.
  6. Exportaciones: las tablas se generan como CSV; el gráfico se dibuja en Canvas y se descarga como PNG; el informe se entrega como documento compatible con Word (.doc); PDF se obtiene mediante el diálogo de impresión del navegador.
  7. Extensión: edita los alias de columnas en findColumn() si tus CSV usan encabezados distintos. Conserva los nombres de los botones y las funciones de exportación al cambiar la interfaz.

No requiere servidor Python para el análisis web. Para ejecutar también el análisis académico de Pandas/NumPy en VS Code usa main.py o el notebook del repositorio.
